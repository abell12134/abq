# A股量化分析 Agent 方案（只分析不交易）

> 只分析、不交易。核心：**可结算预测** + **双时间线追踪** + **champion–challenger 晋升**。
>
> 不重造已有因子挖掘能力（仓库 `quant/factor_lab/` 已是 RD-Agent 式循环）；本方案补的是它们都缺的一层——**预测的可证伪性 + 到期结算 + 用结算校准信任**。
>
> **实现架构（分层 / 模块地图 / 部署）**：[QUANT_AGENT_ARCHITECTURE.md](./QUANT_AGENT_ARCHITECTURE.md)  
> **使用说明（日常操作）**：[QUANT_AGENT_USAGE.md](./QUANT_AGENT_USAGE.md)

---

## 0. 边界声明

- 本系统**评估预测质量，不评估可交易性**。不下单 = 拿不到真实执行反馈（滑点、冲击成本、部分成交、涨跌停未成交）。
- L2 组合的回撤 / 换手 / 波动均为**纸面指标**（假设无摩擦成交）。
- 任何输出**不得暗示「目标收益 X% 可实现」**，只给「目标 vs 历史可达性说明 + 失效条件」。

---

## 1. 目标与边界

### 要做

- L1/L2 可结算预测、L3 状态机、追踪结算驱动校准与权重、旁路搜因子
- 回测仅作**准入门槛**；**历史回测 ≠ 未来收益**

### 不做

- 实盘下单、券商对接、自动交易

---

## 2. 系统原则

1. **可结算才算预测**：标的、方向/目标、期限、结算规则、统计有效样本，缺一不可
2. **双时间线**：离线回测准入 ≠ 在线追踪校准
3. **微调先稳后激**：主路径改置信度/权重/启停；搜因子走旁路
4. **LLM 编排、代码算账**：指标、回测、结算、校准全部确定性代码
5. **无成绩单不荐股**：输出附带近期真实表现（含样本量与置信区间）

## 3. 预测层级与信号源



### 3.1 信号源（先划清边界）


| 环节                      | 由谁产生                                   | 说明                                                        |
| ----------------------- | -------------------------------------- | --------------------------------------------------------- |
| L1/L2 的 claim（涨跌/区间/目标） | **ML 模型**（现仓库 LGBM score）              | LLM **不产生** claim；score → claim 映射 + 模型概率作 raw confidence |
| raw confidence          | 模型概率（如 LGBM predict_proba）             | 未经校准                                                      |
| 校准后 confidence          | Calibrate 模块（代码）                       | Platt / 分桶                                                |
| LLM 职责                  | 编排、解释、Critic 自然语言检查、`factor_lab` 提因子假设 | 不参与预测数值本身                                                 |


> 预测的「数值」来自模型，LLM 只决定「下一步做什么」和「怎么讲」。这条边界保证校准对象明确：**校准的是模型概率 → 实际命中率**。



### 3.2 三层


| 层级          | 性质           | object | claim           | 结算             | 用途          |
| ----------- | ------------ | ------ | --------------- | -------------- | ----------- |
| **L1 单票**   | 可结算预测        | 股票     | 方向 / 区间（见 §4.1） | 命中判定（见 §4.1）   | 个股分析、推荐池    |
| **L2 组合**   | 可结算预测        | 组合ID   | 目标收益 + 风险约束     | 三项裁决（见 §11）    | 「要稳健 X%」类需求 |
| **L3 策略开关** | **状态机**（非预测） | 策略ID   | 启用 + 信任权重       | 由 L1/L2 结算聚合驱动 | 系统自身调权      |


> **L3 不进预测账本**。它是策略注册表 + 权重账本的状态机（champion / challenger / paused），转移由 L1/L2 结算驱动。元决策伪装成预测会造成循环依赖。

## 4. 结算口径（MVP-1 硬前提，第一天冻结）

> 口径不定，后期改一次 = 历史预测全重算、校准全废。



### 4.1 L1 命中定义（原方案缺失，补齐）

claim 分两种，结算逻辑不同：

- **方向预测**（二分类）：claim = {看涨 / 看跌} 相对 benchmark
  - 命中 = `sign(实际超额收益) == 预测方向`；二值 outcome
- **区间预测**（带宽度）：claim = `[low, high]` 超额收益带
  - 命中 = `实际超额收益 ∈ [low, high]`
  - 另记 PIC（覆盖率）与平均带宽，**不与方向命中率混算**



### 4.2 通用口径

- **基准**：写入 claim（沪深300 / 中证500 / 中证全A，按对象选定）
- **复权**：统一后复权（hfq）
- **horizon**：N **交易日**（非日历日）；`resolve_at` = T+N 收盘
- **起止**：T+1 开盘入场，T+N 收盘结算（避免当日反身性）
- **停牌**：停牌日不计入 N；到期日停牌顺延至复牌后首交易日
- **涨跌停**：按收盘价判定命中（不模拟成交）；Critic 标注命中日涨跌停
- **ST/退市**：预测期内 ST/退市，Critic 标记并按特殊规则结算（如提前以事件日结算）

## 5. 双时间线架构

```
线 A 研究准入（慢）
  假设/新因子 → Walk-forward 回测 → 过门槛(多重检验校正) → 进 challenger 池

线 B 预测追踪（主线，快）
  出可结算预测 → 到期结算 → 误差账本 → 校准置信度 / 调权重 / 启停
                              ↑
                    新因子先旁路出预测，不直接改主权重
```

晋升规则统一见 **§8.2**（本节不重复）。

## 6. Agent / 模块划分


| 模块                   | 职责                              |
| -------------------- | ------------------------------- |
| **Supervisor**       | 路由意图：单票 / 组合 / 策略诊断；汇总报告        |
| **Data**             | 行情、复权、基本面、公告、舆情                 |
| **Feature / Factor** | 计算已登记因子；触发搜因子（复用 `factor_lab`）  |
| **Predict**          | 写 L1/L2 预测（claim 来自模型，§3.1）     |
| **Portfolio**        | L2 权重优化                         |
| **Backtest Gate**    | 仅准入；禁止回测闭环刷参                    |
| **Track**            | 到期结算、hit/miss/error、成绩单         |
| **Calibrate**        | 置信度校准、策略权重、降权/暂停                |
| **Critic**           | lookahead/滞后（代码断言）+ 过拟合/话术（LLM） |
| **Report**           | 新预测 + 成绩单 + 失效条件                |


**编排**：LangGraph（状态机 + checkpoint）；内层取数 ReAct，外层研究 Plan-and-Execute。

## 7. 预测账本（仅 L1/L2）

```
pred_id            唯一 ID
level              L1 | L2
object             股票 / 组合ID
claim_type         direction | interval | target  ← 决定结算与校准口径
claim              主张（方向 / [low,high] / 目标+约束）
horizon            N 交易日
benchmark          结算基准（指数 + 口径）
settlement_caliber 口径版本号（升级时全量重算，见 §16.5）
confidence         校准后置信度（raw 见下）
raw_confidence     模型原始概率
strategy_version   策略版本
feature_snapshot   {feature_version, pit_timestamp, content_hash, snapshot_ref}
created_at         生成时间
resolve_at         T+N 收盘
status             pending | resolved | expired | shadow
outcome            结算结果（含 hit/pic/width 等按 claim_type）
error_metrics      误差指标
```

**feature_snapshot 存档策略**（原未定，补）：账本只存 `feature_version + pit_timestamp + content_hash + snapshot_ref`；完整特征向量归档到独立 parquet（按 pred_id 索引），账本只持引用——避免膨胀且可复盘。

另建（L3 在此，不是账本）：

- **策略注册表**：因子定义、版本、状态（champion / challenger / paused）；复用 `factor_lab`，词汇映射 `candidate→challenger / paper_tracking→challenger(tracking) / live→champion / rejected→paused`
- **权重账本**：各策略当前信任权重、滚动表现
- **校准曲线**：按 `claim_type` 分桶（方向命中率 / 区间 PIC 分别画，不混）

## 8. 微调策略



### 8.1 主路径：校准 + 权重（稳）

**MVP-1 只动 confidence，不动 strategy weight**（权重账本 MVP-2 起）。

- 置信度校准：**按 claim_type 分流**
  - 二分类（方向、L2 目标达标）：Platt / 分桶可靠性图
  - 区间：跟踪 PIC vs 名义水平、带宽，不做「命中率校准」
- 滚动窗口更新策略权重（衰减 + 正则 + 换手惩罚）—— MVP-2 起
- **降权/暂停逻辑（选定滚动统计式，弃「连续失效」式）**：
  - 滚动窗口（60 个已结算预测或 60 交易日，取先达）
  - 当滚动命中率下界（Wilson CI lower）**低于随机基准**（方向=0.5）且持续 K 个窗口 → 降权
  - 样本不足（n<30）→ 不评估、不降权，标「样本不足」
  - 严重失效（如低于随机基准 2 倍标准差）→ 直接 paused
  - **不用「连续 N 次 miss」**（对运气敏感，易误杀好策略）



### 8.2 旁路：自动搜新因子 + 晋升（合并原 §5 重复内容）

- **触发**：用户深度分析、策略失效、定期研究
- **搜索空间受先验约束**：价量、基本面、舆情衍生等有理论支撑的因子族
- **流程**：
  1. `factor_lab` LLM 提假设 → 实现 → walk-forward 评估
  2. **多重检验门（按指标选工具，原 DSR 错配已纠）**：
    - 命中率口径 challenger → **二项检验 + Bonferroni/Holm**（N 个并行校正）
    - Sharpe 口径 challenger（如 L2 组合）→ Deflated Sharpe Ratio
    - 不混用
  3. 通过 → 登记 challenger，并行出预测并追踪
  4. 最小样本外窗口（≥30 已结算或 40 交易日）+ 优于 champion + 通过多重检验 → 晋升，继承权重槽位
  5. 未晋升前不进主组合推荐权重

> 搜因子=提假设；多重检验门=过滤假阳性；追踪线=决定信不信。

## 9. Critic 的硬规则

**代码断言（MVP-1 必须有最小版，不待 LLM Critic）**：

- **Lookahead 拦截**：`feature_snapshot` 必须 point-in-time；任何用未来数据的全局统计（全样本均值/标准化）是**硬错误**，预测不予发出
- **训练/追踪不重叠**：线 A walk-forward 训练段与线 B 追踪段不得共享数据
- **数据滞后**：晚于预测日可用的数据不得入特征

**LLM Critic（MVP-2 起，叠在代码断言之上）**：

- 过拟合迹象、涨跌停/停牌影响、话术夸大（禁「必涨/稳赚」等不可证伪措辞）、失效条件是否齐备

---



## 10. 成绩单（统计门槛）

每张成绩单必须含：

- **样本量 n**（已结算预测数）
- **按 claim_type 分别统计**（方向命中率 vs 区间 PIC，不混算）
- **命中率 + Wilson 置信区间**
- **n < 30 → 标「样本不足，仅供参考」，不得进主推荐**
- 分桶校准图（按 claim_type）
- 失效/暂停状态标注

---



## 11. 「稳健 / 目标收益」如何落地（L2）

L2 结算**三项独立裁决**（原未定义基准，补齐）：

1. **超额裁决**：组合超额收益 vs **基准指数**（同 L1 caliber）是否为正
2. **目标裁决**：实现年化收益 ≥ 用户目标？
3. **约束裁决**：最大回撤 / 年化波动 / 单票·行业上限 / 换手 是否在约束内（纸面指标，见 §0）

三项各自二值，**不假设 L1 准 → L2 达标**（高命中票可能同行业聚集，分散后失效）。

组合优化：

- 输入权重来自校准后的策略信任，不是裸因子暴露
- 在约束内逼近目标收益（或最大化风险调整收益）

输出必须带：目标 vs 历史可达性说明、近期追踪成绩（含统计量）、失效条件。

## 12. 冷启动（原方案缺失，补）

系统上线第一天零已结算预测，按「无成绩单不荐股」原则无法输出。处理：

- **Shadow 期**（前 N0≈40 交易日）：系统照常出预测并标记 `status=shadow`，但**不进用户推荐**；成绩单标「shadow，无追踪成绩」
- **伪成绩单（仅内部）**：用 walk-forward 样本外段的回测结果生成「伪成绩单」，明确标注「回测非追踪」，**只供内部 sanity，不得对外荐股**
- **毕业条件**：某策略/层级累计已结算 n ≥ 30 且通过最小校准 → 从 shadow 转为可推荐
- 用户可见推荐在毕业前一律带「系统冷启动中，预测仅供观察」水印

## 15. 结算层测试策略（原缺失，补）

结算代码是确定性核心，需**金标准用例**：

- 固定历史窗口 + 固定预测 → 预期 outcome（hit/miss/pic/width）
- 覆盖：涨跌停、停牌顺延、除权日、ST、方向 vs 区间、L2 三项裁决
- CI 每次跑；口径升级后用例同步更新并标注 caliber 版本

### 16.3 成本预算（原缺失，补）

- L1 推理：全市场 ~5000 票 × LGBM，**无 LLM**，毫秒级
- LLM 调用：仅 Critic 解释（top-K 推荐子集）+ `factor_lab` 搜因子批次；估算**每日数十次**，非数千次
- 结算/校准：纯代码，可忽略



### 16.4 成功标准（产品验收）

1. 任意推荐可追溯到可结算预测与追踪成绩（含样本量/置信区间）
2. 主路径调权可解释（为何降权/暂停）
3. 新因子不能「回测好看就上主推荐」——经多重检验门 + 样本外追踪晋升
4. 用户同时看到：今日观点 / 历史预测准不准 / 系统当前信任谁
5. **结算口径可升级**：每次升级全量重算历史预测并标注 `settlement_caliber` 版本，保证可追溯可重算（非「永不变」）



### 16.5 口径版本机制

`settlement_caliber` 是版本号字段。口径升级时：旧预测保留原 caliber 标注，按新口径全量重算生成新 outcome 列，**两者并存可对比**。校准曲线按 caliber 分版本画，避免跨口径污染。
