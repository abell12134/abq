## 评估指标

### 核心指标（重点关注）
1. **夏普比率** (Sharpe Ratio)
   - 目标: > 1.0
   - 计算: (年化收益 - 无风险利率) / 年化波动

2. **最大回撤** (Max Drawdown)
   - 目标: < 25%
   - 观察: 回撤幅度和恢复时间

3. **年化收益** (Annual Return)
   - 目标: > 15%
   - 对比: 是否优于原策略

### 辅助指标
4. **换手率** (Turnover)
   - 观察: 是否因集中持仓而增加
   - 控制: 日均换手 < 10%

5. **胜率** (Win Rate)
   - 观察: 盈利交易占比
   - 目标: > 55%

6. **超额收益** (Excess Return)
   - 对比: 相对基准 (中证500) 的超额
   - 目标: 年化超额 > 9%

## 评估时间节点

### 第 5 个交易日（初步观察）
- [ ] 策略是否正常运行
- [ ] 持仓数量是否在 10-15 只
- [ ] 单票权重是否超过 10%
- [ ] 换手率是否正常

### 第 10 个交易日（中期评估）
- [ ] 累计收益 vs 原策略
- [ ] 最大回撤情况
- [ ] 是否触发风控熔断

### 第 20 个交易日（最终评估）
- [ ] 夏普比率计算
- [ ] 年化收益估算
- [ ] 超额收益计算
- [ ] 决定是否推广到主账户

## 风险提示

1. **样本外风险**: 参数优化基于历史数据，未来表现可能不同
2. **集中风险**: 持仓集中可能放大个股风险
3. **流动性风险**: 中小盘股票可能流动性不足
4. **市场环境**: 不同市场环境下策略表现可能差异较大

## 决策流程

```
第 5 天: 策略正常运行?
    ├─ 否 → 排查问题，考虑暂停
    └─ 是 → 继续观察

第 10 天: 累计收益 vs 原策略?
    ├─ 差距 > -5% → 继续观察
    └─ 差距 < -5% → 评估原因，考虑调整

第 20 天: 夏普比率 > 1.0?
    ├─ 是 → 推广到主账户
    └─ 否 → 分析原因，决定是否继续
```
